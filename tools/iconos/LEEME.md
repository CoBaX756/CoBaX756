# Logos de las tecnologías

Los SVG de esta carpeta vienen de [Simple Icons](https://simpleicons.org) (dominio público, CC0).
Se guardan aquí para que el perfil no pida nada a ningún servidor externo al cargarse.

Los logotipos son marcas de sus propietarios (PHP, Laravel, Docker, etc.) y se usan solo para
indicar con qué tecnologías trabajo.

Para actualizarlos: descargar `https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<nombre>.svg`.
